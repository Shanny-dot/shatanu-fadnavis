- **Build Tool:** Vite, PostCSS

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone git@github.com:Shanny-dot/shatanu-fadnavis.git
cd shatanu-fadnavis

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
